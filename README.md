To compile all the files together use the following terminal command(Make sure you are in /tests):
    g++ -std=c++17 main.cpp TextEditor.cpp Clipboard.cpp Cursor.cpp SkipList.cpp Document.cpp Display.cpp InputHandler.cpp ConsoleHelpers.cpp FileHandler.cpp -o editor.exe

Then run the following command in terminal to run the text editor:
    ./editor.exe
